# Changelog

## 0.1.0 — 2026-08-23

Initial standalone PACT skill and reference implementation.

- Defined immutable signed atomic commits in a content-addressed causal DAG.
- Defined external evidence references, hierarchical namespaces, scoped
  delegation, epochs, advisory leases, revocation, and signed checkpoints.
- Defined content-addressed schema/policy and deterministic projection contracts.
- Added staged production plan, threat model, adoption guide, event catalog, and
  design-decision record.
- Added CLI/library for initialization, key generation, trust bootstrap, append,
  verification, indexing, query, checkpointing, and directory sync.
- Added JSON Schemas, examples, and conformance/end-to-end tests.
