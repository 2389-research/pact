# Reader fact rubric

Report the exact namespace, subject, requested source, and inspected heads/frontier.
Report check names, outcomes, event refs, and their exact source scope.
Report each finding's review ref, ID, severity, summary, status, and explicit resolution refs.
Report recorded decisions, their check/review refs, policy, and concurrent conflicts.
Separate recorded decisions from supported local acceptance and explain blockers.
Report actually checked evidence locators, digests, bytes, match status, and durable source.
Report declared actions, actor, blocking refs/findings, and their own source scope.
Do not describe historical actions as current merely because they remain listed.
State local-root authority, shared-key independence, unknown global completeness, and execution limits.
Report unread pages, unresolved references, errors, truncations, and unsupported inferences.
Preserve exact refs in each scenario; do not choose a winner for concurrent incompatible decisions.
